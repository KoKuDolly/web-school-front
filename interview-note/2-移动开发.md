# 移动设备 适配

## 参数概念

**pt** ios 开发的单位，以 iphone3gs 为基准，1 物理像素点的宽度为 1pt，后续设备的 dpr（devicePixelRatio） 有 2 或 3 的，那么 1pt = dpr \* 物理像素点宽度。

**dp** google 开发的单位，与 pt 原理类似，基准是 mdpi 320\*480

**ppi** pixels per inch

**dpi** dots per inch

## 适配过程

### 像素

css pixel 和 pt， dp 是一样的

### visual viewport

window.innerWith

pc 端

可视视口 受到 缩放比例的影响，浏览器窗口相同的情况下，缩放比例越大，可视视口宽度越小；缩放比例越小，可视视口宽度越大

可视视口与浏览器窗口的大小有关，缩放比例相同的情况下，浏览器窗口越大，可视视口宽度越大；浏览器窗口越小，可视视口宽度越小

### layout viewport

document.documentElement.clientWidth

移动端

衡量单位: CSS px。
默认值: 宽度有默认值，由手机浏览器定义。一般是 768px ~ 1024px 之间，常见默认值为 980px。
移动端设置：可以通过 meta 的 viewport 标签中 width 设定；例如 <meta name="viewport" content="width=400">
缩放，滑动页面，翻转手机屏幕等均不影响布局视口。
使用媒体查询时 max-width 和 min-width 的值指的也是布局视口的宽

### 默认

布局视口尺寸 = 可视视口尺寸

缩放比例 根据 理想视口计算 = 理想视口尺寸 / 可视视口尺寸

### 理想视口

逻辑分辨率组成的视口就是理想视口（ideal viewport）

特点， device-width 就是指 理想视口的宽度，理想视口尺寸不能设定，不能改变，只与 设备物理像素，dpr，浏览器有关。

dpr 设备像素比 = 物理像素数 / 理想视口尺寸

理想视口尺寸 = screen.width

dpr = window.devicePixelRatio

<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no"/>

时，布局视口尺寸 = 可视视口尺寸 = 理想视口尺寸，dpr = 物理像素数/理想视口尺寸 = 物理像素数 / 布局视口尺寸
